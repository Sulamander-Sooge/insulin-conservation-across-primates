# insulin-conservation-across-primates
This bioinformatics project investigates the conservation of the amino acid sequence for insulin pre-proteins across 6 select primate species to practice and test my skills in:

1) Biopython
2) Sequence retrieval suing BLAST
3) MSA using Clustal Omega
4) Molecular phylogenetics and tree construction
5) Column-wise analysis of aligned sequences

This project serves to lay a foundation to my portfolio as a researcher interested in computational biochemistry and drug research.
